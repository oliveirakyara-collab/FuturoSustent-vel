Sobre o Projeto
O projeto Futuro Sustentável busca promover ideias e soluções para um mundo mais sustentável.

  Objetivos
- Incentivar práticas sustentáveis
- Divulgar conhecimento ambiental
- Promover energias renováveis
- Apoiar inovação sustentável

  Áreas de Interesse
- Economia Circular
- Energias Renováveis
- Preservação Ambiental
- Cidades Inteligentes
- Agricultura Sustentável
